# Roadmap 180 days → ~2027-02-01

Горизонт: 2026-07-23 → 2027-02-01 (~27 недель). Спринты по 2 недели (кроме коротких фаз).
Бюджет: учёба 1ч/день; просмотр вакансий ~1ч/неделя (поиск делает buscador/бот).

## Фазы

### Фаза A — Foundation (спринты 1–3, ~6 недель)
Цель: сильный EN-нарратив, портфолио-артефакты, ясный visa pitch для работодателей.
- CV/LinkedIn consistency (EN)
- 2 публичных артефакта: threat note + agent demo README
- abogado: shortlist путей к trabajo por cuenta ajena + чек-лист документов
- Ежедневно: tech/interview mix через motivador

### Фаза B — Signal & apply (спринты 4–7, ~8 недель)
Цель: стабильный поток релевантных вакансий и качественные отклики.
- buscador топ-5 каждый день → ты 1ч/нед shortlist
- Трекер `data/applications.csv`: статусы found → applied → interview
- Cover/LinkedIn message шаблоны под AI Security / AI Engineer / AI Data Analyst
- entrevistador: gap-анализ каждой shortlist-вакансии

### Фаза C — Interview intensity (спринты 8–11, ~8 недель)
Цель: уверенные интервью на EN; готовность к ES small-talk.
- 3 mock/неделя (entrevistador)
- System design агентов + AI threat scenarios
- Salary/sponsorship narrative отработан
- Углубление пробелов из реальных отказов/фидбека

### Фаза D — Offer & move readiness (спринты 12–14, ~6 недель)
Цель: оффер с формальным трудоустройством и старт visa/extranjería с работодателем.
- Сравнение офферов (права, relocation, timing)
- Документы по выбранному path (abogado checklist)
- Логистика переезда (город гибкий)
